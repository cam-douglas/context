# Decision: product name is Context

- Status: accepted
- Date: 2026-08-28
- Owner: user/operator

## Decision

The Max for Live device and later VST3/AU host are named **Context**.

## Context

The launch plan used a temporary working name (Forma). The owner renamed the product to Context before Build.

## Consequences

- Task ID: `20260828-context-ai-arrangement`
- Blueprint: `docs/blueprints/2026-08-28_context.md`
- Device source: `max/context/`
- Sidecar package: `context_sidecar`
- Environment-variable prefix: `CONTEXT_`
- This repository is also named `context`. Docs must say "Context the device" when the product and the repo could be confused.

## Rejected alternatives

- Forma, Stator — superseded by owner naming.
