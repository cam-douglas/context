# Context claims

## Allowed when verified

- Context is a Max for Live insert that can hear the host track, read the open Live Set, and write clips through the Live Object Model.
- Users steer it with a prompt, optional drop-in loop, and optional reference, plus reverence and abstraction knobs.
- Analysis and planning run in a local sidecar.
- V1 does not rearrange Logic or GarageBand projects.
- Cross-DAW support, when shipped, drops stems and MIDI.

## Denied

- "Works as an arranger in GarageBand / Logic / FL."
- "Includes MusicGen commercially."
- "Trained on your tracks in the cloud" (V1 is local).
- Any conversion, revenue, or market-size figure that was not measured.

## First audience

Ableton and Max for Live users. Publish only after owner approval and a working harness.
